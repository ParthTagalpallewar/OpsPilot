# 2026-11-23 · Partial evidence reports

Isolated file-reader failures in the resource and Payment graph branches. If usable evidence remains, the report includes partial coverage and source issue metadata. It keeps independent observations and withholds comparisons, links, or change attribution that require missing evidence. An unavailable capture with no usable evidence still fails the investigation.

Added tests for a corrupt Payment trace and a missing Ad incident window. Live source acquisition failures and runbook backend failures still need their own partial-result handling.
